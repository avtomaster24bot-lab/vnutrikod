# Внутрикод — экспериментальный сайт Марины Степановой

Статический сайт (GitHub Pages) без фреймворков и сборщиков. HTML генерируется Python-скриптом.

**Живой сайт:** https://avtomaster24bot-lab.github.io/vnutrikod/

## Структура
| Путь | Что это |
|---|---|
| `assets/config.js` | **Единый файл настроек**: цены, контакты, ссылки на оплату, даты, Метрика, ИИ-эндпоинт |
| `assets/app.js` | Общая логика: фон-«космос», цены из конфига, окно записи → Telegram, UTM, «Мой путь», подарок перед уходом |
| `assets/tools.js` | Навигатор (ИИ + сценарий), тесты, карта дня, Мини-Лила, дыхание, челлендж, «Мой путь» |
| `assets/catalog.js` | Генерируется: продукты, статьи, тесты, клетки Лилы для JS |
| `_src/gen.py` | Генератор всех страниц, `sitemap.xml`, `robots.txt` |
| `_src/art.py`, `articles1-4.py` | Статьи энциклопедии (с источниками) |
| `_src/tests_data.py` | Тесты-самонаблюдения |
| `_src/extra.py` | Клетки Мини-Лилы, карты дня, челлендж, темы навигатора |
| `_src/data.py`, `_src/reviews.py` | Тренинги/модули/мини и настоящие отзывы (из основного сайта) |
| `_src/images.py`, `_src/pdfs.py` | OG-картинки/иконки и PDF-подарки (Chrome headless) |

## Как обновить
```bash
python3 _src/gen.py      # страницы + catalog.js + sitemap
python3 _src/images.py   # OG-картинки (если менялись статьи/тесты)
python3 _src/pdfs.py     # PDF-подарки
```
Цены и контакты меняются **только** в `assets/config.js` (генератор берёт оттуда цены для HTML без JS, JS — подставляет на лету).
После изменений CSS/JS увеличьте `V` в `_src/gen.py` (сброс кэша `?v=N`).

## Навигатор: два режима (ИИ-помощник / сценарий)
Навигатор на главной и на `/navigator/` работает в двух режимах:

1. **ИИ-помощник** — если в `assets/config.js` заполнен `aiEndpoint` (URL), свободный текст пользователя отправляется POST-запросом:
   ```json
   {"messages":[{"role":"user|assistant","content":"..."}], "page":"navigator/", "mode":"navigator"}
   ```
   Ожидаемый ответ (JSON):
   ```json
   {"reply":"текст ответа", "suggestions":[{"label":"Тест «Индекс самозванца»","url":"/vnutrikod/testy/samozvanec/"}]}
   ```
   Таймаут — `aiTimeoutMs` (по умолчанию 12 000 мс). В окне показывается метка **«ИИ-помощник»**.
2. **Сценарий (офлайн)** — если `aiEndpoint` пустой, сервер не ответил за таймаут, вернул ошибку или пустой `reply`, навигатор **молча** переключается на встроенное дерево решений (4 вопроса → маршрут: подарок → статья → тест → живой шаг). Метка — **«Навигатор»**. Кнопки-варианты всегда работают по сценарию.

**Бэкенд:** планируется Supabase Edge Function — прокси к ИИ-провайдеру. **API-ключ хранится только в секретах функции, никогда во фронтенде.** Функция должна:
- принимать формат выше, разрешать CORS для `https://avtomaster24bot-lab.github.io`;
- иметь системный промпт: подбирать материалы сайта, не ставить диагнозов, при признаках кризиса давать контакты экстренной помощи (`/vazhno/#help`);
- ограничивать частоту запросов.

Подключение: `aiEndpoint: "https://<project>.supabase.co/functions/v1/<name>"` в `assets/config.js`, увеличить `V`, пересобрать.

## Аналитика
`yandexMetrikaId` в `config.js` пустой — нужен **новый счётчик** Метрики для этого домена. Цели: `cta_click`, `tg_click`, `test_done`, `navigator_route`, `minilila_done`, `gift_prompt`.

## Принципы
Никаких выдуманных отзывов и статистики, никаких медицинских обещаний. Тесты — самонаблюдение, не диагностика. Прогресс хранится только в localStorage.
